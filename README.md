## 0.5.5 변경
- 도구걸이 그리기 방식 개편:
  - 평평한 바닐라식 손 도구(검·곡괭이·도끼 등)는 기존 그대로.
  - 그 밖의 아이템(쇠뇌, Create 렌치 등 3D 모델 도구)은 손 변환 대신 모델의 실제 형태를 재서 건다 — 긴 축을 세로로, 단면이 넓은 쪽(머리)을 아래로, 가장 얇은 면을 바깥으로, 형태의 가운데를 걸이 위치에.
  - 전용 렌더러인데 기본 모델 면을 가진 아이템(Create 렌치)은 면으로 형태를 재고 그리기는 원래 렌더러에 맡겨 움직이는 부품까지 나온다.
  - 삼지창, 그리고 손에는 긴 3D 모델·인벤토리에는 그림을 쓰는 모드 무기(쇠스랑 등)는 인벤토리 그림 모델로 건다.
- 방패는 도구걸이에 걸 수 없다 (태그 `trailpack:hook_excluded`, 기본: 방패 + `#c:tools/shield`).
- 위아래가 반대로 걸리는 모드 도구는 태그 `trailpack:hook_flipped` 에 넣어 뒤집을 수 있다 (기본 비어 있음).

## 0.5.0 변경

- Curios 가 필수에서 선택으로. 배낭은 바닐라 몸 장비 칸에 멘다 (Shift+클릭 또는 끌어 놓기). Curios 가 있으면 등 칸에도 멜 수 있다
- 배낭은 한 번에 하나만: 몸 칸에 배낭이 있으면 등 칸에, 등 칸에 있으면 몸 칸에 못 멘다
- 몸 칸에 멘 배낭은 갑옷주머니 교환(웅크리기+B)에서 몸 칸을 건너뛴다 → 배낭이 벗겨지지 않고, 주머니의 몸통 갑옷은 그대로
- 갑옷주머니의 몸통 칸에 배낭을 넣을 수 없음
- 몸 칸에 멘 배낭도 등에 같은 모습으로 그려짐 (플레이어만)

## 빌드

1. JDK 21 설치 (이미 있으면 생략)
2. NeoForge 버전은 모드팩과 같은 21.1.252 로 맞춰 두었다 (`gradle.properties`)
3. 이 폴더에서 실행
   - Windows: `gradlew.bat build`
   - macOS/Linux: `./gradlew build`
4. `build/libs/trailpack-0.5.5.jar` 를 모드팩 `mods` 폴더에 넣는다
5. 시험 전에 Sophisticated Backpacks 는 빼 둔다 (B키 충돌)

빌드 오류가 나면 오류 메시지 전체를 Claude에게 붙여 넣으면 된다.
0.3.x 에서 만든 시험용 배낭은 부착물 칸 구조가 바뀌어 다시 만들어야 한다.

## 키

| 키 | 동작 |
| --- | --- |
| B | 멘 배낭 열기 |
| 웅크리기 + F (손 바꾸기 키) | 갑옷주머니와 입은 갑옷 맞바꾸기 (갑옷주머니가 없으면 바닐라 손 바꾸기) |
| G | 오른쪽 부착물 |
| 웅크리기 + G | 왼쪽 부착물 |
| V | 위 부착물 (침낭 꺼내기 / 묶기) |

양옆 규칙: 손에 든 것이 그 칸에 들어가는 것(도구걸이 = 도구·랜턴, 간식 주머니 = 음식)이면 맞바꾸고(칸이 비면 넣기, 같은 것이면 채우기), 아니면 칸의 것을 주 손으로 꺼낸다. 들고 있던 것은 인벤토리 → 배낭 → 바닥 순서로 간다.

## 시험 순서 (오류 원인을 좁히기 위해 이 순서로)

1. **배낭 본체** — 조합(네 모서리 실, 상하좌우 가죽, 가운데 빈칸) → 바닐라 몸 장비 칸에 멤(Curios 가 있으면 등 칸도 가능, 한 번에 하나만) → B로 열기 → 들고 우클릭으로 설치(등쪽 면이 나를 향함) → 우클릭으로 열기 → 부숴서 회수(내용물 보존) · 인벤토리 아이콘이 지금 모습 그대로 입체로 보이는지
2. **강화·수납 규칙** — 배낭 위아래 셜커 껍질로 9×1 → 9×3 한 번에 (재강화 안 됨, 내용물 보존) · 배낭·셜커 상자 넣기 금지 · 셜커 상자 안에 배낭 금지 · 깔때기 · 비교기 · 피스톤(깨짐) · 폭발
3. **부착물 화면** — 조합(가죽 가운데, 실 왼쪽 = 간식 주머니 / 오른쪽 = 도구걸이 / 위 = 침낭끈 / 아래 = 갑옷주머니) → 화면 왼쪽 패널(배낭 위치 그대로: 윗줄 침낭 ↑ / 가운데 줄 ← 왼쪽 · 오른쪽 → / 아랫줄 갑옷주머니 + 갑옷 4칸 가로) → 오른쪽·왼쪽 칸에 도구걸이·간식 주머니(간식 주머니는 하나만), 위 칸에 침낭끈, 앞 칸에 갑옷주머니 → 내용물 칸 X 풀림 → 부착물을 빼거나 바꾸면 안 맞는 내용물이 떨어짐 · 툴팁에 키 안내
4. **G / 웅크리기+G** — 도구걸이: 도구 들고 → 맞바꾸기 / 빈손이나 다른 것 들고 → 꺼내기(들던 것은 인벤토리로) / 빈 도구걸이에 도구 넣기 · 랜턴 64개까지 걸기, 걸린 랜턴 빛(설치 시 블록 빛, 착용 시 셰이더 손 조명 + 동적 조명), 영혼 랜턴 피글린 퇴치 · 간식 주머니: 그쪽 키를 누르고 있으면 손에 든 것과 상관없이 먹기(떼면 취소, 그릇 요리는 그릇이 인벤토리로)
5. **V** — 빈손이나 다른 것 들고 V → 침낭이 손으로 나옴(들던 것은 인벤토리로) → 우클릭으로 설치 · 침낭 들고 V → 넣기/맞바꾸기 · 침낭: 밤에만 눕기, 리스폰 안 바뀜, 네더·엔드는 메시지만
6. **핫바 표시** — 배낭을 메면 핫바 오른쪽에 ← → 2칸(양옆만), 부착물 없는 위치는 어둡게
7. **외형** — 도구걸이에 건 도구가 실제 아이템 모양·손에 든 것과 같은 크기로 손잡이 위로 옆면에 바짝 걸림 · 랜턴은 바닐라 랜턴 모양 그대로 · 설치·착용·아이콘이 같은 모습
8. **다른 플레이어** — 남이 멘 배낭을 빈손 우클릭 → 주 인벤토리만 보임 → 상대가 멀어지거나 죽으면 창 닫힘
